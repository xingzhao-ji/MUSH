# Development status

This is experimental 0.6.0 source derived from combined243 and curated into a portable repository. It retains the paving preview, safe-placement/controller work, visual paw correction, shared environment and refreshed audio. Ordinary development uses normal input and a separate `MUSH-dev` save profile. A separate [mac063 candidate](MAC-CANDIDATE.md) is now exported and tested. The archive's 0.5.7 app remains the accepted reference build; 0.5.5 remains rollback.

**The leafier-flower successor passes native placement/wind checks, gameplay acceptance and the source frame-time check. The frozen mac063 app still fails its recorded p95 limit. The full paving contact-coverage gate and whole-game acceptance remain open. The private GitHub baseline was uploaded and independently cloned successfully.** See [verification evidence](VERIFICATION.md) and the [compact summary](verification-summary.json) for exact scope and receipts.
